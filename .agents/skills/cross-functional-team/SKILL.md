# Cross-functional Team

다음 custom agent에게 서로 독립적인 관점의 작업을 위임합니다.

- `FE`: 프론트엔드 영향과 구현·검증 항목
- `BE`: 서버·데이터·권한·운영 영향
- `PM`: 사용자 문제·범위·완료 기준
- `PD`: 사용자 흐름·UI·접근성·브랜드 일관성

모든 결과를 기다린 뒤 합의 사항, 이견, 결정이 필요한 질문, 권장 범위와 검증 기준을 종합합니다. 동시 실행 한도보다 역할이 많으면 남은 역할을 이어서 실행합니다.

FE, BE, PD 중 두 개 이상의 직군이 함께 검토하거나 의사결정하면 PM을 함께 호출합니다. 다른 직군의 결과를 취합한 뒤 PM에게 결정 사항과 후속 작업을 전달하고, 저장소 workflow에 따른 task worktree의 `docs/meetings/<topic>.md`에 회의 결과를 작성하거나 기존 문서를 갱신하게 합니다. 회의록에는 대화 전문 대신 주제, 참여 직군, 결정 사항과 근거, 담당자별 후속 작업, 완료 기준과 미결 질문만 남깁니다.

기본적으로 네 agent는 검토와 계획만 수행합니다. 구현이 요청된 경우에도 같은 파일을 병렬 수정하지 않으며, 부모 에이전트가 프론트엔드 또는 백엔드 agent 한 명만 구현 담당으로 지정하고 나머지는 검토 역할로 유지합니다.
