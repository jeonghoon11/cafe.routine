# 루틴 페이지 방향성 회의

## 주제

현재 Cafe Routine 공개 페이지의 제품 방향과 우선 개선 범위

## 참여 직군

FE, BE, PM, PD

## 결정 사항과 근거

Black & White 브랜드와 사진 중심 표현을 유지하고, 홈에서 메뉴와 방문 정보로 이어지는 현재 구조를 기본 방향으로 유지합니다.

- 홈의 `메뉴 보기`, `오시는 길`에서 핵심 정보로 한 번에 이동할 수 있습니다.
- 메뉴 페이지는 공개 메뉴와 가격을 제공합니다.
- 방문 페이지는 주소, 영업시간, 전화번호, 네이버 지도와 Instagram을 제공합니다.
- 시각 방향을 재설계하기보다 데이터 조회 안정성, 모바일 가독성과 동작 접근성을 먼저 보완하는 것이 현재 범위에 적합합니다.
- 메뉴 품절, 임시 영업, SEO와 분석은 운영 정책이나 기준 정보가 먼저 필요해 이번 구현에서 제외합니다.

## 역할별 수행 결과

- FE: 공개 페이지 구조와 구현 영향을 검토하고, 홈 이미지 조회와 모바일·reduced-motion 관련 최소 변경을 반영했습니다.
- BE: Supabase 공개 데이터 흐름을 검토하고 홈에 필요한 이미지 수만 조회하도록 제한할 것을 제안했습니다.
- PM: 방문자 필수 정보, 검색 유입, 핵심 행동, 재방문 가치, 라이팅과 운영 정책을 검토하고 후속 결정 항목을 정리했습니다.
- PD: Black & White 사진 중심 방향을 유지하고, 모바일 hero 가독성과 모션 접근성을 보완하도록 검수했습니다.

## 구현·검증

이번 구현은 다음 3건입니다.

- `getHomeMedia`가 정렬된 공개 홈 이미지 4개만 조회하도록 `.limit(4)`를 추가했습니다.
- 모바일 hero 제목 크기를 `23vw`에서 `20vw`로 조정했습니다.
- `prefers-reduced-motion: reduce`에서는 전역 smooth scroll을 해제했습니다.

검증 상태는 다음과 같습니다.

- `git diff --check`: 통과
- 변경된 TypeScript 파일 대상 lint: 통과
- `pnpm lint`: 통과
- `pnpm exec next typegen`: 통과
- `pnpm typecheck`: 통과
- Playwright 320px, 375px, 430px: hero 제목 잘림과 가로 overflow 없음
- Playwright reduced-motion: `scroll-behavior: auto` 적용 확인
- 로컬 `/`, `/menu`, `/visit`: HTTP 200 확인
- 브라우저 console에서 `favicon.ico` 404를 발견했으며 페이지 동작에는 영향이 없습니다.

## 보류 결정

- `is_available` 메뉴를 숨길지 `품절`로 표시할지
- 임시 휴무·단축 영업의 입력, 노출, 만료와 갱신 담당 정책
- absolute canonical에 사용할 운영 도메인
- 검색 유입과 핵심 행동을 측정할 분석 도구
- 분석 도구 도입에 따른 개인정보·쿠키 고지 범위

## 담당자별 후속 작업과 완료 기준

- FE
  - 공식 favicon 자산이 정해지면 metadata와 함께 추가합니다.
  - 메뉴·영업시간 데이터가 0건일 때 안내할 empty state를 구현합니다.
- BE
  - 품절 표시 정책이 정해지면 `is_available`이 공개 메뉴에 합의된 방식으로 반영되게 합니다.
  - 임시 영업 정책이 정해지면 예외 영업이 방문 페이지에 우선 노출되고 만료 후 제거되게 합니다.
- PM
  - 운영자와 품절·임시 영업 정책, canonical 도메인과 분석 도구를 확정합니다.
  - 분석 도입 후 메뉴·방문·지도·전화·Instagram 행동의 기준선을 수집하고, 데이터가 쌓인 뒤 개선 목표를 정합니다.
- PD
  - 모바일·desktop에서 Black & White 위계와 사진 가독성을 확인합니다.
  - keyboard focus와 reduced-motion 설정에서 핵심 탐색 흐름이 유지되는지 검수합니다.

이 문서는 같은 주제의 후속 회의에서 결정 사항과 검증 결과를 갱신합니다.
